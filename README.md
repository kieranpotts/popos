# Pop_OS!

My Pop_OS! config, for backup and migration purposes.

## Documentation

The new "cosmic" desktop does not offer a complete export/import feature, except
for the **Desktop > Appearance** options in the Cosmic Settings app. My desktop
appearance configuration is exported to the `./src/Dark.ron` file.

The cosmic desktop stores the rest of its configuration in `~/.config/cosmic`.
This single directory holds the full configuration for your theme, desktop
layout, panel and dock config, keyboard shortcuts, and everything else. There's
no built-in export/import feature, but you can migrate it manually. To export,
simply create an archive of the directory:

```
$ tar -czf src/cosmic-settings-backup.tar.gz -C ~/.config cosmic
```

Then restore it on the target machine:

```
$ tar -xzf src/cosmic-settings-backup.tar.gz -C ~/.config
```

The `-C` flag is important on both the export and import commands to ensure that
the archive is created as a relative path from `~/.config`.

It's not recommended to symlink the `~/.config/cosmic` directory.

Desktop images are in the `./src/Documents/Backgrounds` directory. Simply copy
this directory to `~/Documents/Backgrounds`, or setup a symlink:

```
$ ln --symbolic --force "${PWD}/src/Documents/Backgrounds" ~/Documents/Backgrounds
```

The `./src/pop_os_settings.dconf` file is a backup of my application settings.
It is generated by running the following command:

```
$ dconf dump / > src/pop_os_settings.dconf
```

To import:

```
$ dconf load / < src/pop_os_settings.dconf
```

> **Tip:** If you want to fully replicate all application settings, you should
> migrate both the `~/.config` and `~/.local` directories.
